## 🛠️ Tech Stack & Key Features

### Core Technologies
- **Frontend Framework:** React 18, TypeScript, Next.js
- **Styling:** Tailwind CSS v4, Custom CSS Modules
- **Animations:** GSAP (GreenSock Animation Platform) for high-performance scroll and hover effects
- **3D Interactive Experience:** Three.js, React Three Fiber, Draco Compression for optimized 3D assets
- **Backend & AI Integration:** Google Gemini AI API, FastAPI, GitHub Actions

### Highlights
- **Interactive 3D Landing Page**: Featuring customized 3D models with high-precision animation triggers.
- **GSAP Scroll Smoothing**: Sophisticated scroll-driven UI transformations and project transitions.
- **Dynamic Content Injection**: Fully data-driven architecture using `config.ts` for rapid project and resume updates.
- **AI-Powered Contact System**: Custom workflow for handling inquiries with smart auto-responses.
